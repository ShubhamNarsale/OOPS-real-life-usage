# Unit I – Programs

### 1. Smart Farm Sensor Monitor

A farm sensor monitoring program that stores readings from multiple sensors. Each sensor contains information such as sensor ID, moisture level, and recording time. The program also allows a sensor reading to be updated when a new reading is received.

**Concepts used:**

* Classes and Objects
* Encapsulation
* Private Data Members
* Constructors
* Constant Member Functions
* STL Vector
* Updating Object Data

### 2. Student Attendance Tracker

A student attendance program that records the attendance of students and calculates their attendance percentage based on the number of classes attended and total classes conducted.

**Concepts used:**

* Classes and Objects
* Encapsulation
* Constructors
* Member Functions
* Constant Member Functions
* Attendance Percentage Calculation

### 3. Product Inventory Manager

An inventory management program that stores product information such as product ID, name, price, and available stock. It also maintains the total number of products using a static data member.

**Concepts used:**

* Classes and Objects
* Constructors and Destructors
* Getter Functions
* Static Data Members
* Static Member Functions
* Constant Member Functions

### MINI_PROJECT: Smart Home Manager

A menu-driven smart home management program that handles different devices such as Smart Light, Thermostat, Security Camera, and Door Lock.

**Concepts used:**

* Inheritance
* Protected Members
* Virtual Functions
* Function Overriding
* Runtime Polymorphism
* Virtual Destructor
* Dynamic Memory Allocation
* Menu-Driven Programming

# Unit IV – File Handling

### 1. Student Record File System

A student record system that stores student details such as roll number, name, and marks in a CSV-like text file. The program writes records to the file and reads them back to generate a student report.

**Concepts used:**

* `ofstream`
* `ifstream`
* Text File Writing
* Text File Reading
* File-Open Validation
* Classes and Objects
* Class Methods
* `getline()`
* `stringstream`
* CSV-Style Data Parsing
* `stoi()`
* `stod()`

### 2. Server Log Analyzer

A server log analyzer that reads a server log file and identifies `ERROR` and `CRITICAL` messages. Matching log entries are stored in a vector and displayed as a critical event report.

**Concepts used:**

* File Reading
* `ifstream`
* Line Parsing
* `getline()`
* STL Vector
* String Searching
* `find()`
* Defensive Error Handling
* Log Analysis

### 3. Binary File for Fixed-Size Records

A binary file application that stores fixed-size image metadata records containing image width, height, and format.

**Concepts used:**

* Binary File Mode
* `ios::binary`
* `write()`
* `read()`
* Fixed-Size Structures
* Sequential Record Retrieval
* Binary File Validation
* `reinterpret_cast`

# How to Run

1. Clone or download this repository.
2. Open the required `.cpp` file.
3. Compile the program using a C++ compiler.
4. Run the generated executable.

### Linux / macOS

```bash
g++ program.cpp -o program
./program
```

### Windows

```bash
g++ program.cpp -o program.exe
program.exe
```
